# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Contact the
maintainers privately through a
[GitHub security advisory](https://github.com/Jasonrve/AegisScan/security/advisories/new),
including the affected version, reproduction steps, impact, and
any relevant logs with secrets removed.

We will acknowledge reports within five business days, keep the reporter
informed as the investigation progresses, and coordinate disclosure after a
fix or mitigation is available. Never include repository credentials or raw
secret values in a report.
