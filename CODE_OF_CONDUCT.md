# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be respectful, assume good faith, and keep discussion focused on the work.

Report unacceptable behaviour privately to the maintainers through a
[GitHub security advisory](https://github.com/Jasonrve/AegisScan/security/advisories/new)
or by contacting the repository owner via their GitHub profile.
